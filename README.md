# Due Date

A family baby pool: everyone adds their name, Aimee locks the names, a random draw sets the picking order (Aimee first), and each person picks one date. The closest guess wins.

Live (hidden link): https://thespectrumtechengine.com/due-date/

Shared data lives in the Chop the Check Realtime Database under `dueDate/`. The rule is in `database-rules.txt`.
Testing on this computer: open `http://localhost:<port>/?mock` (pretend database; add `&phone=b` for a second phone).
